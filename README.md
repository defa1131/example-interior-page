# example-interior-page

Этот проект является одной из первых работ на курсе. В нем использованы технологии Flexbox для создания адаптивного дизайна. Но на данный момент адаптивная версия сайта еще полностью не реализована.

## Описание

- **Сайдбар**: В проекте реализован сайдбар, который представляет собой навигационное меню.
- **Страницы**: На данный момент запрограммирована только одна страница, остальные страницы не кликабельны.
- **Страница с видео интерьерами**: Основное внимание уделено странице, на которой представлены видео интерьеров.
